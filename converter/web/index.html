GT2 PSP
Converter

Turns your own Gran Turismo 2 discs into a native PSP version. Everything is built here, on your computer, from your discs - nothing of the game is downloaded.
1Your discs

Pick the disc image for each mode: .cue, .bin or .bin.ecm (the files are only read, never changed). Each disc is checked at once. Supported: GT2 USA (Simulation Mode Rev 2, Arcade Mode), GT2 Europe and Japan (both discs) and the fan mod GT2 Plus (Beta v6.1 and Beta 7). One disc is enough; with both discs of a version you get a start menu to pick the mode. Each version gets its own PSP folder and save data (GT2PSP, GT2PSPEU, GT2PSPJP, GT2PLUS, GT2PLUSEU).

Simulation Mode

2Your PSP

Connect the PSP by USB and start USB Connection in its settings menu, then pick the memory stick. The converter installs the game there right after converting. If the game is already on the PSP, only the files that changed are copied - usually the start file and the game program, not the 600 MB data pack. Your save data and settings stay. Leave this empty to just build the folder on your computer.

5Your save (optional)

  
Bring a GT2 save from an emulator or a real memory card: a whole memory card (.mcr,
    .mcd, .srm, .gme, .vmp, ...) or single save files
    (.mcs, .psx, .psv, ...). It is put on the PSP as IMPORT.MCD and
    the game takes it over at its next start. The card it had until then is kept as BACKUP.MCD in the same
    folder. A save only works with the same version (USA, Europe, Japan) it was made with.
